# Ganitha Kaduwa LMS — UI Prototype

A responsive front-end prototype for the Ganitha Kaduwa learning portal, branded with the supplied logos and contact/social links.

## Included pages
- Home / landing page
- Login and student registration
- Grade selection and course catalogue
- Lesson detail / resource list
- Recorded lessons library
- Timetable and calendar
- Payments and receipt submission modal
- Quizzes and results
- Student dashboard
- Teacher/admin dashboard
- Study materials
- Announcements
- Student profile and preferences

## Run locally
No build step is required. Open `index.html` in a modern browser. For best results, use VS Code with the Live Server extension and open the project folder.

## Important: prototype status
This ZIP contains the **front-end UI prototype**, not a production-ready LMS backend. Login/register, payment processing, receipt storage, quiz saving, Zoom joining, private video playback, student-specific access, database storage, notifications and admin publishing are demo interactions only. Do not enter real passwords, payment details or student personal data. Before launch, connect a secure backend/database, payment gateway, protected video hosting, role-based access control, backups and production hosting. Sample dashboard numbers and payment/quiz records are illustrative placeholders.
